# Logo

Ilagay dito ang logo ng TCC.

| File | Saan lumalabas | Payo |
|---|---|---|
| `logo.png` | Splash screen (pagbukas ng app), 132×132 ang ipinapakita | PNG na square, 512×512 pataas, may transparent na background |

**Palitan lang ang `logo.png`** — hindi na kailangang baguhin ang code.
Pagkatapos palitan, patakbuhin ang `flutter run` o `flutter build apk` para
mapasama ito.

Kapag nawala o nasira ang file, hindi bumabagsak ang app — may
pansamantalang icon na lumalabas sa halip.

## Icon ng app (ang nasa home screen ng telepono)

Iba ito sa splash logo. Nasa
`android/app/src/main/res/mipmap-*/ic_launcher.png` ang mga iyon —
kailangan ng ilang sukat (48, 72, 96, 144, 192 px). Sabihin lang kapag
nailagay mo na ang logo dito at ako na ang bahala doon.
